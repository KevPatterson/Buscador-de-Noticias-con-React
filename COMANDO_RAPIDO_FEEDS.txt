     dominio: 'juventudrebelde.cu',
     nombre: 'Juventud Rebelde',
     feed: 'https://www.juventudrebelde.cu/rss/noticias',
     tieneContentEncoded: false,
   }


3. CONFIGURAR RT CON FALLBACK (Corto Plazo)

   Archivo: src/config/fuentes-rss.js
   
   {
     dominio: 'rt.com',
     nombre: 'RT',
     feed: 'https://actualidad.rt.com/feeds/all.rss',
     fallback: 'https://rt-english.com/rss/news/',
     headers: {
       'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
     }
   }


4. DESBLOQUEAR CUBADEBATE Y TELESUR (Mediano Plazo)

   Agregar headers de navegador:
   
   headers: {
     'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
     'Accept': 'application/rss+xml, application/atom+xml'
   }
   
   Implementar reintentos con backoff exponencial


5. USAR GOOGLE NEWS COMO FALLBACK UNIVERSAL

   Patrón:
   https://news.google.com/rss/search?q=site:[dominio]&hl=[idioma]&gl=[pais]
   
   Ejemplos:
   - Cubadebate: https://news.google.com/rss/search?q=site:cubadebate.cu&hl=es-419&gl=CU
   - ACN: https://news.google.com/rss/search?q=site:acn.cu&hl=es-419&gl=CU
   - teleSUR: https://news.google.com/rss/search?q=telesur&hl=es

💡 TIPS IMPORTANTES
═════════════════════════════════════════════════════════════════════════════════

1. URLS CON GEOÍP:
   Si un feed no resuelve, podría ser geo-bloqueado
   → Prueba con VPN desde otro país
   → O usa fallback a Google News

2. BLOQUEOS ANTI-BOTS:
   Si ves ECONNRESET, el servidor rechaza automatización
   → Cambia User-Agent
   → Agrega headers de navegador
   → Implementa backoff exponencial

3. FEEDS 404:
   Si devuelve 404, la URL no existe
   → Prueba variaciones
   → Contacta al administrador
   → Usa agregador como fallback

4. VALIDACIÓN RÁPIDA:
   Abre la URL en el navegador
   Si ves un feed RSS, el servidor la permite
   Si no funciona con curl, es anti-bots

5. FALLBACKS:
   Siempre ten un plan B
   Google News funciona como agregador universal
   Nunca dejes un feed sin alternativa
